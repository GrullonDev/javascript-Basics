# 📘 Fundamentos de JavaScript

Este repositorio contiene una recopilación de conceptos fundamentales de **JavaScript**, con ejemplos prácticos y explicaciones claras. Ideal para quienes inician en la programación o desean reforzar sus conocimientos en este lenguaje esencial del desarrollo web.

---

## 🧠 ¿Qué aprenderás?

- Sintaxis básica de JavaScript
- Tipos de datos (`string`, `number`, `boolean`, `null`, `undefined`, etc.)
- Variables y constantes (`var`, `let`, `const`)
- Operadores (aritméticos, lógicos, de comparación)
- Estructuras de control (`if`, `else`, `switch`, `for`, `while`, etc.)
- Funciones (declarativas, expresivas, arrow functions)
- Arrays y objetos
- Métodos comunes de arrays (`map`, `filter`, `reduce`, etc.)
- Manejo de errores (`try`, `catch`)
- Introducción básica al DOM (opcional)

## 1. Clonar Repositorio

```bash
git clone https://github.com/tuusuario/javascript-basics.git
cd javascript-basics
```

## 2. Abrir los archivos con tu editor de código (recomendado: VS Code)

```bash
code .
```

## 3. Ejecutar ejemplos con Node.js

```bash
node 01-variables/variables.js
node 02-operadores/operadores.js
```

# 🤝 Contribuciones

¿Quieres aportar un ejemplo, corregir un error o mejorar el contenido?

```bash

# Luego abre un Pull Request desde GitHub
```
